# Electronic E-Commerce

A responsive electronic e-commerce website built using React.js and Vite. The project uses modern frontend libraries and styling tools to create an interactive shopping experience.

## 🚀 Tech Stack

- **React.js** – UI development
- **Vite** – Development server and build tool
- **JavaScript (ES Modules)** – Application logic
- **Tailwind CSS** – Utility-first styling
- **AOS** – Scroll animations
- **Lucide React** – Icon library
- **React Icons** – Additional icons
- **React Slick** – Carousel and slider components
- **ESLint** – Code quality and linting

## 📦 Prerequisites

Before running the project, ensure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git (optional, for cloning the repository)

## 🛠️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/IT21223808/E-shop.git
```

### 2. Navigate to the frontend directory

```bash
cd E-shop/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

## 🏗️ Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the Vite development server |
| `npm run build` | Builds the application for production |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs ESLint to check code quality |

## 🔨 Production Build

Create an optimized production build:

```bash
npm run build
```

The generated production files will be available in the `dist/` directory inside `frontend`.

To preview the production build locally:

```bash
npm run preview
```
